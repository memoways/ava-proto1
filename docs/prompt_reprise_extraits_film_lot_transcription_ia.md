# Prompt de reprise — Extraits du film, lot 1b (transcription IA sur demande)

À copier dans un nouveau chat Ava. Contexte : [plan](plan_extraits_film_pas_vu.md) (section Lot 1b), [tâche Notion](https://app.notion.com/p/10162322e59583bbb825816717ee18ca), lot 1 livré (PR #233).

---

Objectif : pouvoir, depuis l'onglet Admin › Expérience › Extraits, générer par IA la **transcription de la parole** d'un extrait du film, sur le même principe que la « Description IA ». Chaîne voulue par Ulrich : ajouter la vidéo dans Notion, la labelliser (Nature, Personnages, Dialogue, thèmes), puis générer depuis l'application la description IA et la transcription ; un humain relit ensuite et coche « Transcription vérifiée ».

État vérifié (21 novembre) : propriétés Notion « Transcription », « Dialogue » (Parlé/Silencieux) et « Transcription vérifiée » créées ; colonnes `transcription`, `dialogue`, `transcription_verified` de `public.video_triggers` appliquées via Lovable (migration 0022) ; `sync-notion` les lit (absent/effacé → null/false) ; onglet Extraits en place (`VideoTriggersEditor scope="extracts"`, statut `extractTranscriptStatus`). Modèle à imiter : Edge Function `supabase/functions/describe-video/index.ts` et `_shared/videoDescription.ts` (admin seulement via `requireAdmin`, Gemini via OpenRouter, une seule propriété Notion écrite, miroir Supabase, garde `assertOnly…`, `selectVideosToDescribe`, bouton unitaire + lot avec progression dans `VideoTriggersEditor`).

Périmètre :
1. Nouvelle Edge Function (ex. `transcribe-video`) + helpers purs dans `_shared/` testés par vitest : analyse d'**un extrait** (`nature = extract` et Dialogue = Parlé, sinon refus explicite : jamais silencieux, jamais « non renseigné », jamais une cinématique transformée).
2. **Piège à traiter d'abord** : la rendition d'analyse actuelle (`pickAnalysisVariant`) est **sans son**. Trouver une rendition Gumlet avec piste audio (ou extraire l'audio) tenant dans la limite de taille de Gemini ; si impossible, échec explicite (`no_audio_rendition`, `video_too_large`), jamais de transcription inventée. Vérifier le résultat sur un vrai extrait parlé de la base avant de conclure.
3. Prompt de transcription : paroles réellement dites, dans l'ordre, locuteurs identifiés quand c'est possible (sinon « Voix 1 », « Voix 2 »), passages inaudibles notés `[inaudible]`, aucune interprétation, aucune complétion, aucune traduction, pas de description visuelle ; aucune parole détectée → ne rien écrire et le signaler (« aucune parole détectée »).
4. **Écriture** : seulement la propriété Notion « Transcription » (puis `video_triggers.transcription`). Ne jamais écrire « Description », « Description IA », « Dialogue » ni « Transcription vérifiée ». Une transcription générée reste non vérifiée ; une transcription déjà cochée « vérifiée » n'est jamais écrasée sans réanalyse explicite confirmée (la case est alors décochée). Limite de Notion sur la taille d'un rich_text : découper en plusieurs éléments.
5. **Back-office** (onglet Extraits seulement) : « Transcrire » par extrait parlé ; « Transcrire les extraits parlés sans transcription (N) » avec confirmation et progression ; interrupteur « Retranscrire les transcriptions existantes non vérifiées » ; erreurs par vidéo ; transcription visible avec son statut. Les extraits silencieux ou sans Dialogue n'ont pas de bouton actif et disent pourquoi.
6. Optionnel, à demander à Ulrich avant : proposer un Dialogue (parlé/silencieux) détecté par l'IA sans l'écrire. Par défaut, ne pas le faire : le label vient de la labellisation humaine.

Limites : base Caractères Notion en lecture seule ; dans Vidéos AVA, écrire uniquement « Transcription » ; coût IA : afficher le nombre de vidéos avant un lot, confirmation obligatoire ; aucune production ; secrets côté serveur ; déploiement de l'Edge Function par Lovable (dire à Ulrich ce qu'il faut coller dans le chat Lovable) ; Gami DigiDouble exclu ; ne pas toucher à la sélection ni à la lecture des extraits (lot 2).
Validations : lint, typecheck, `test:regression`, tests de garde, CI `regression-gates` verte sur le HEAD exact ; l'essai réel sur un extrait parlé n'est pas une preuve de qualité de transcription (relecture humaine par Romed à signaler comme non faite).
