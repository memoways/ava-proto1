# Reprise — parler anglais à Nuance

Ce prompt ne lance rien tant qu'Ulrich ne le demande pas. L'écoute Deepgram en français, anglais et allemand est dans le lot qui précède. Le chantier multilingue complet reste [M1](prompt_reprise_multilingue_lot_m1.md).

## État

- Deepgram Nova-3 : `language=multi`, indications `fr`, `en`, `de`. L'ancien `fr-FR` est relu ainsi.
- Nuance, mode Texte d'Ava : le pipeline Ava produit la réplique, Nuance reçoit seulement la consigne « Say only this ». Pas le RAG, pas les prompts, pas l'intonation du TTS.
- Nuance parle anglais avec la voix de Sam, Sonia ou Mira. Une réplique française peut être refusée.
