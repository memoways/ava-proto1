# Proposition — vocabulaire des vidéos (Romed)

À valider. Rien n'est écrit dans Notion depuis ici. Les propriétés **Émotion**, **Enjeu** et **À l'écran** n'existent pas encore dans « 🎬 Vidéos AVA » (lu le 21 novembre 2026). **Thèmes** existe. La base Caractères n'est pas concernée.

**Personnages** garde son sens : qui peut parler pendant la vidéo (Max, Emma, Ava, Léo, Tous). **À l'écran** est un autre champ : qui est visible. « Tous » n'y a pas sa place.

## Thèmes — nettoyage

Options actuelles : famille, disparition, confiance, pandémie, secrets, amitié, trahison, contexte, patricarcat, Contamination.

- **patricarcat** → **patriarcat** (faute). Reporter les vidéos qui portent l'ancienne option, puis la retirer.
- **Contamination** et **pandémie** disent la même chose. Garder **pandémie** (déjà en minuscules, comme les autres). Reporter les vidéos qui n'ont que Contamination, puis retirer Contamination.
- **contexte** ressemble au champ Contexte, pas à un thème. Le retirer si aucune vidéo ne s'en sert vraiment.

Le reste peut rester. Ajouter ou retirer un terme ensuite ne demande aucun changement de code : on resynchronise.

## Émotion — valeurs de départ

peur, culpabilité, tendresse, colère, déni, honte, deuil, méfiance, espoir, soulagement.

## Enjeu — valeurs de départ

protéger, dire la vérité, perdre, trahir, cacher, avouer, accuser, réparer, rester, partir.

## À l'écran — valeurs de départ

Max, Emma, Ava, Léo, Peter, Mona.

Une personne visible qui ne parle pas (Peter, Mona) peut être à l'écran sans être dans Personnages.

## Après validation

Créer les trois multi-sélections dans Vidéos AVA, appliquer le nettoyage des thèmes, puis resynchroniser. Un terme ajouté, renommé ou retiré apparaît au Game Master et dans l'onglet Décisions vidéo sans modification de code. Une valeur hors liste reste visible, marquée « hors liste », pour décider s'il faut l'ajouter.
